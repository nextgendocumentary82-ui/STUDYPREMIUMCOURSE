STUDY PREMIUM COURSE - ADVANCED PURCHASE PLAN + ADMIN ACCESS

1) Admin -> Add/Edit Course
   Use "Purchase plans" field, one plan per line:

   30 Days|30|199
   3 Months|90|399
   6 Months|180|599
   1 Year|365|999
   Lifetime|0|1499

   Format: Label|Days|Price
   Days = 0 means Lifetime.

2) Student flow
   - Student opens paid batch.
   - Student selects duration/plan.
   - Razorpay / Cashfree / UPI QR creates the order for the exact server-validated plan price.
   - Successful payment becomes PAID, but batch remains WAITING FOR ADMIN.

3) Admin payment/access flow
   - For QR, first verify the actual bank/UPI transaction.
   - Paid orders show Selected Plan + Access Status.
   - Grant Access -> enter days (selected plan is suggested automatically).
   - Edit Access -> enter new days; duration restarts from edit time.
   - Remove Access -> batch is immediately locked; payment record stays safe.
   - Restore / Grant Access -> re-enable removed/expired access.

4) Student account
   - PAYMENT VERIFIED • WAITING FOR ADMIN while pending.
   - ACTIVE + remaining days + expiry after grant.
   - EXPIRED / REMOVED access cannot open the batch.

5) Security
   - Plan price/days are validated on the server; frontend values are not trusted.
   - Razorpay/Cashfree verification remains server-side.
   - QR never unlocks from UTR/screenshot alone.
   - /api/access/create also checks active admin-granted ownership.

Existing old active ownerships are migrated to ACTIVE automatically on server startup.
